Chuck Engine

An icebreaker that runs on other people’s jokes.

API IntegrationSocial / PartySmall Project

This is a simple, lighthearted icebreaker game where players tell jokes and interact with each other. It uses APIs to fetch or generate jokes, making each round quick, spontaneous, and easy to play.

The game was designed as a small project focused on experimenting with API integration while creating a fun social experience.
