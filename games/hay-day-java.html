Hay Day — Java

A farming game rebuilt from scratch, with no engine underneath it.

JavaNo EngineSystems & UI

Hay Day is a Java-based recreation of the farming game Hay Day, developed entirely from scratch without using a dedicated game engine. I built the complete game, including its core gameplay systems and a functional UI, entirely in Java.

The project was a significant technical challenge because implementing systems that a game engine would normally provide required extensive amounts of code and manual development. Building the game this way gave me a deeper understanding of what actually happens underneath a game engine — from managing game logic and UI to structuring and connecting the different systems.

More importantly, the project became a stepping stone toward my next stage of development: learning to work with professional game engines. After experiencing firsthand how much has to be built manually, I wanted to understand not only how to use an engine, but why engines are designed the way they are and what they abstract away. This gave me a much stronger technical foundation for engine-based game development.
