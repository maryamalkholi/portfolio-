Project Goal

To build a miniature search engine that can crawl webpages, analyse the connections between them, calculate their importance using the PageRank algorithm, and visualise the results.

What I Did

I developed a web-crawling and ranking pipeline in Python. I collected webpages and their links, stored the relationships between them, implemented the PageRank calculation through iterative processing, and generated the resulting data for an interactive visualisation.

Idea Behind the Project

The project models the web as a network of interconnected pages. Pages that receive links from other important pages are given greater importance, allowing the system to calculate a ranking for each page rather than simply treating all pages equally.

Key Features

  • Web crawler for discovering linked pages
  • Graph-based representation of webpage relationships
  • Iterative PageRank calculation
  • JSON data generation
  • Interactive D3.js network visualisation
  • Visual representation of page importance

Technical Focus

Python, web crawling, graph algorithms, PageRank, iterative algorithms, data processing, JSON, D3.js, and interactive data visualisation.
