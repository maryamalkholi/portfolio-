Geodata Mapping

Turning raw location strings into a map you can read.

PythonAPI IntegrationMapping
Draft copy. You didn’t send a description for this one, so I wrote a placeholder — replace it with your own words whenever you like.

Geodata Mapping is a Python project that reads a list of raw location strings, resolves each one into geographic coordinates through a geocoding API, stores the results locally so the API is only queried once per location, and then renders every resolved point onto an interactive map.

Technical Focus

  • Consumed a geocoding API and handled its JSON responses
