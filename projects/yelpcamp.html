YelpCamp

A full-stack campground platform with real user-generated content.

Node.js · ExpressMongoDBFull Stack

YelpCamp is a full-stack web application for discovering and reviewing campgrounds. The project was designed to simulate a real-world platform where users can browse campground listings, view details, create new listings, and share reviews.

The application combines a dynamic frontend with a backend server and database, allowing user-generated content to be stored and managed rather than simply displaying static information.
