Forkify

Recipe search built on live API data.

JavaScriptREST APIAsync

Forkify is a web application that allows users to search for recipes and explore detailed cooking instructions through an interactive interface. The project was built to practise working with external APIs and transforming retrieved data into a responsive, user-friendly web experience.

Users can search for recipes, browse search results, and open individual recipes to view their ingredients and preparation information. The application dynamically retrieves and displays recipe data rather than relying on a fixed collection of locally stored content.

Technical Focus

  • Integrated an external Recipe API to retrieve real-time recipe data
  • Built dynamic search functionality and result rendering
  • Worked with asynchronous JavaScript and API requests
  • Processed JSON data returned from the API
  • Created reusable UI components for recipe results and detailed recipe views
  • Practised structuring a web application around external data and user interaction

The project strengthened my understanding of API integration, asynchronous programming, DOM manipulation, and data-driven web interfaces.
